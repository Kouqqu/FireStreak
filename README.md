# FireStreak (FDStreak)

Плагин для Minecraft-серверов (Paper / Purpur / Spigot 1.16+), добавляющий систему ежедневных стриков («огоньков») за вход на сервер.

## Возможности

- Подсчет дней непрерывного входа игроков (с учетом часового пояса сервера).
- Отображение текущего стрика в Action Bar при входе (настраиваемые цвета и длительность).
- Награды каждые N дней (по умолчанию каждые 7 дней): выдача предметов, салют и уведомление на экране.
- Звуковые эффекты при обычном входе и получении награды.
- Автоматическое сохранение данных игроков в data.yml.

## Установка

1. Скачайте файл FDStreak-1.0.jar из раздела [Releases](https://github.com/Kouqqu/FireStreak/releases).
2. Поместите его в папку plugins вашего сервера.
3. Перезагрузите сервер.
4. При необходимости настройте plugins/FireStreak/config.yml.
