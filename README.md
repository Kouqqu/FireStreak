# FireStreak (FDStreak)

[English](#english) | [Русский](#русский)

---

## English

A lightweight Minecraft plugin for Paper / Purpur / Spigot (1.16+) that rewards players for consecutive daily logins with fire streaks.

### Features

- Tracks consecutive daily login streaks based on the server's timezone.
- Displays current streak in the Action Bar on join (customizable HEX colors and duration).
- Periodic rewards every N days (custom items, firework, and on-screen title).
- Sound effects on daily join and milestone rewards.
- Automatic player data saving in data.yml.

### Installation

1. Download FDStreak-1.0.jar from [Releases](https://github.com/Kouqqu/FireStreak/releases).
2. Place it into your server's plugins/ folder.
3. Restart or reload your server.
4. (Optional) Configure plugins/FireStreak/config.yml.

## Русский

Плагин для Minecraft-серверов (Paper / Purpur / Spigot 1.16+), добавляющий систему ежедневных стриков («огоньков») за вход на сервер.

### Возможности

- Подсчет дней непрерывного входа игроков с учетом часового пояса сервера.
- Отображение текущего стрика в Action Bar при входе (настраиваемые цвета и длительность).
- Награды каждые N дней (по умолчанию каждые 7 дней): выдача предметов, салют и уведомление на экране.
- Звуковые эффекты при обычном входе и получении награды.
- Автоматическое сохранение данных игроков в data.yml.

### Установка

1. Скачайте файл FDStreak-1.0.jar из раздела [Releases](https://github.com/Kouqqu/FireStreak/releases).
2. Поместите его в папку plugins вашего сервера.
3. Перезагрузите сервер.
4. При необходимости настройте plugins/FireStreak/config.yml.
