# 🔥 FireStreak (FDStreak)

Лёгкий и красивый плагин для **Paper / Purpur / Spigot** (поддержка Minecraft 1.21+ и выше), добавляющий механику ежедневных стриков (огоньков) за вход на сервер, как в популярных сервисах.

---

## ✨ Возможности

- **🔥 Ежедневный стрик (огоньки):** Подсчитывает дни непрерывного входа каждого игрока с привязкой к настраиваемому часовому поясу (`timezone`).
- **📊 Отображение в Action Bar:** При входе игроку плавно выводится красивый Action Bar (например, `🔥 7 дн. подряд`) с поддержкой любых кастомных HEX-цветов.
- **🔊 Звуковые эффекты:** Воспроизведение звуков при ежедневном входе и получении наград. Поддерживаются как Bukkit enum (`ENTITY_PLAYER_LEVELUP`), так и современные ключи реестра (`entity.player.levelup`), а также кастомные звуки ресурспаков.
- **🎁 Награды за регулярность:** Каждые $N$ дней (по умолчанию каждые 7 дней) игрок получает настраиваемые награды:
  - Выдача предметов прямо в инвентарь (с выпадением рядом, если инвентарь полон);
  - Праздничный цветной салют;
  - Поздравительное сообщение и заголовок на экране (Title).
- **💾 Надежное сохранение данных:** Прогресс игроков автоматически сохраняется в `data.yml` по UUID.

---

## ⚙️ Требования

- **Java:** 21 или новее
- **Ядро сервера:** Paper / Purpur / Spigot (1.21.x, 26.x+)

---

## 🛠️ Конфигурация (`config.yml`)

```yaml
settings:
  # Часовой пояс сервера (например: Europe/Moscow, UTC)
  timezone: "Europe/Moscow"
  # Длительность показа Action Bar (в секундах)
  action-bar-duration: 5

colors:
  fire: "#FF4500"   # Цвет огонька
  number: "#FFA500" # Цвет цифры
  text: "#FFD700"   # Цвет текста

sounds:
  # Поддерживаются имена Bukkit и ключи реестра Minecraft
  daily-login: "entity.player.levelup"
  weekly-reward: "ui.toast.challenge_complete"

rewards:
  weekly-interval: 7
  items:
    - "DIAMOND_ORE:3"
    - "EXPERIENCE_BOTTLE:5"
    - "GOLDEN_APPLE:1"

messages:
  weekly-title: "&6&l🔥 НЕДЕЛЬНЫЙ СТРИК! ({days} дн.)"
  weekly-subtitle: "&eВы получили награду за верность серверу!"
```

## 🔨 Сборка проекта

Для сборки `.jar` плагина используется Maven:

```bash
mvn clean package
```

Готовый файл плагина будет находиться в папке `target/FDStreak-1.0.jar`.
